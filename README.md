# XBrowser SHIELD – signierte Update-Informationen

Dieses Repository enthält nur die Update-Datei, die die GitHub-Version von
[XBrowser SHIELD](https://github.com/anonymex3/XBrowser-SHIELD-DOWNLOADS) höchstens alle sechs Stunden abruft:

- `public/android/security.json` – neueste Version, Download-Adressen, Gültigkeit
- `public/android/security.sig` – ECDSA-P-256-Signatur dieser Datei

Die App vertraut der Datei **nur**, wenn die Signatur zum öffentlichen Schlüssel in der App passt; der
Speicherort spielt dafür keine Rolle. Der private Schlüssel liegt nicht in diesem Repository.
